# AI Timetable Generator

## Overview
AI Timetable Generator is a web-based application that automatically generates academic timetables for colleges. It reduces manual effort by assigning subjects, faculty, classrooms, and time slots while following scheduling constraints.

## Features
- Automatic timetable generation
- Faculty management
- Subject and curriculum management
- Classroom allocation
- Department and branch support
- User-friendly web interface
- Database integration using SQLite

## Technologies Used
- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS

## Project Structure
```
app.py                 # Main Flask application
models.py              # Database models
ai_module.py           # Timetable generation logic
curriculum_data.py     # Curriculum management
templates/             # HTML templates
static/                # CSS and static files
requirements.txt       # Project dependencies
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/Devika764/AI-TimeTable-Generator.git
```

2. Navigate to the project folder

```bash
cd AI-TimeTable-Generator
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```
